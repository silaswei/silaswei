## 🧭 工程理念

- **从问题出发**：先弄清使用场景和边界，再选择技术方案。
- **优先复用**：先寻找已有实现和成熟依赖，在确有需要时再自行构建。
- **保持简洁**：重视清晰的命名、合理的职责划分与低耦合设计。
- **重视验证**：关注工具能否在实际场景中稳定工作，也关注文档和使用体验。
- **持续迭代**：先完成可用的版本，再根据反馈逐步改进。
